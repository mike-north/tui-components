# Future Components

## Graph/Diagram Component

- [ ] **node-and-branch diagram**: A component for rendering node-and-branch style diagrams, such as:
  - Git commit graphs showing commits and branches
  - Decision trees
  - Workflow diagrams
  - DAG visualizations

  This would be similar to what `git log --graph` produces, but as a reusable TUI component with customizable node labels, branch colors, and layout options.

  Package name: `@tuicomponents/graph` or `@tuicomponents/diagram`
